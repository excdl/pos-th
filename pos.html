印表機與 Google 試算表設定

支援藍牙、USB、Wi-Fi 熱感印表機，資料永久儲存在您的 Google 試算表。

01. 選擇印表機連線方式

尚未配對藍牙裝置（請使用 Chrome 開啟並開啟印表機電源）
尚未連接 USB 序列埠（若為一般 Windows 驅動印表機，可選「系統印表機」）
只要您的電腦已安裝好 USB 或 Wi-Fi 熱感印表機驅動，即可直接列印 58mm / 80mm 單據。若要完全自動免按確認，可在 Chrome 捷徑加上 --kiosk-printing 參數。
適用純 Wi-Fi IP (Port 9100) 且未安裝電腦驅動的機種，需於店內電腦執行 node print-bridge.mjs。
